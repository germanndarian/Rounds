# Rounds

A social drink tracker for nights out with friends. Native iPhone app (Swift / SwiftUI) on a Supabase backend.
Crews start a **Night** together, log drinks with one tap, share a live feed and disposable-camera photos,
and wake up to a story-style **morning recap**. The product is framed around **memories and nights out, never volume**.

What's built and what's next, and the Supabase setup guide, live outside this repo in the maintainer's personal OS:
`~/Documents/Projects/personal-os/projects/Rounds/` (`Rounds roadmap.md`, `Rounds Supabase setup.md`).
The roadmap there is ticked off automatically from commits. Keep docs out of this repo: README.md and this file only.

### Product / App Store
- Apple rejects apps that encourage excessive drinking. **No leaderboards or rankings by drink count**, no "drink more" copy.
  Rank and celebrate bars visited, badges, photos and streaks of nights out instead. Profile stats never show drink totals.
- The app is 18+ (highest age rating). The age gate in onboarding is a hard stop with no retry loop.
- The BAC estimate is opt-in, shown as a range, always carries "Estimate only. Not for driving decisions.", and is **never shared** with the crew.
- Disposable-camera photos stay sealed until **10:00 the next morning**. The unlock must be enforced server-side, not just hidden in the UI.

## Commands
```sh
xcodegen generate                       # after adding/removing files or editing project.yml
xcodebuild -scheme Rounds -destination 'generic/platform=iOS Simulator' build
xcodebuild test -scheme Rounds -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
supabase migration new <name>           # then write SQL in supabase/migrations/
supabase db push                        # apply migrations to the hosted project
```
Debug builds accept `-startScreen onb|home|crew|map|profile|live|recap` to open a screen directly.
The Profile gear menu has prototype toggles (empty Home, replay onboarding).

## Architecture & conventions
- `AppState` (`@MainActor @Observable`) is injected with `.environment(app)`. Views read it with `@Environment(AppState.self)`.
  It is currently in-memory with sample data. Phase 1 replaces it with Supabase-backed data.
- Navigation: native `TabView` (Home, Crew, Map, Profile). Live Night and Recap are `fullScreenCover`s driven by
  `app.showingLive` / `app.showingRecap`. Get home safe is pushed inside Live Night's `NavigationStack`.
- Toasts: `app.show(toast:)`, rendered by the `.toasts()` modifier (apply it to each full-screen cover's root too).
- Haptics via `.sensoryFeedback`. Timers use `Text(date, style: .timer)` with `.monospacedDigit()`.
- Unfinished integrations are marked `// TODO:` (backend, camera, location, scanner) or `// TODO(design):`.

## Design
- Source: Claude Design project **"Rounds Prototype"**
  (`https://claude.ai/design/p/12366273-24ae-40ff-acf5-25d84067897a`, file `Rounds Prototype.dc.html`),
  design system **Nocturne**. It is readable via the DesignSync tool after `/design-login`.
- Always use tokens from `Theme` (`Theme.bg`, `.surface`, `.text`, `.accent`, the `neutral100–900` and `accent100–900` ramps,
  `.section`/`.sectionGlow`), never ad-hoc colors. Fonts: `.heading(size)`, `.body(size)`, `.mono(size)`.
- Nocturne look: near-black grounds, one blurple accent (#9184D9) used as **line and glow**, outlined primary actions
  (`AccentPillStyle`), hairline secondary actions (`OutlinePillStyle`), rules that fade at both ends (`FadingDivider`),
  film-stamp mono metadata, polaroid photo frames.
- Deviations from the prototype: SF Pro and SF Symbols instead of Inter and Phosphor; dark mode only; uses the
  prototype's **A** variants (Home "Recap hero", Live "Feed + grid", Recap "Type-led").
  The shot and cocktail glyphs are stand-ins (`TODO(design)`).
- Bottom-third primary actions, minimum 44pt tap targets. The app is used one-handed, in the dark, sometimes tipsy.
